# OpenLLM for Mac

Downloads and updates for the OpenLLM desktop app. This repository holds
releases only; there is no source code here.

**Download:** [openllm.sh/download/mac](https://www.openllm.sh/download/mac)

- macOS 12 or later, Apple silicon and Intel (one universal app).
- Signed with a Developer ID and notarized by Apple.
- The app updates itself. Each release lists the SHA-256 of every file in
  `SHA256SUMS`.

Beta builds (for `dev.openllm.sh`) are published as pre-releases.

Questions or problems: [openllm.sh](https://www.openllm.sh).
